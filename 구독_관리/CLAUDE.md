# 구독_관리 폴더 작업 규칙

클로드 등 구독형 서비스의 사용량·비용을 트래킹하는 자료를 보관하는 폴더.
아래 규칙은 저장소 마스터 규칙(`GitHub\Claude\CLAUDE.md`, `사업/창업/CLAUDE.md`, `대학원/CLAUDE.md`)의
문서 관리 규칙을 이 폴더에도 동일하게 적용한 것.

---

## ★ 문서 생성 규칙 — md를 원본으로, html은 스크립트로 생성

**html을 직접 작성·편집하지 않는다.** md를 원본으로 쓰고, 아래 도구로 html을 생성한다.

```
python3 "_도구/build_doc.py" 문서.md          # 같은 폴더에 문서.html 생성
```

- 도구 위치: `구독_관리/_도구/build_doc.py` (창업·대학원 사본과 동일 스크립트 — 스타일 바꿀 때만 함께 동기화)
- 의존성: `pip install markdown --break-system-packages` (스크립트가 자동 설치 시도)

## ★ 파일명 규칙

- 형식: `{문서명}_YYYYMMDD_HHMM_(claude|제이).{확장자}`
- 시간은 **한국시간(KST) 기준** — `TZ='Asia/Seoul' date` 명령으로 확인 후 사용
- md와 html은 **같은 버전명(같은 날짜·시각)으로 함께 저장**

## ★ 버전 관리 — 업데이트 시 이전 버전은 `99 이전 버전/`으로 이동

내용을 업데이트할 때마다:
1. 새 버전명(`{문서명}_YYYYMMDD_HHMM_claude`)으로 md 작성 → `build_doc.py`로 html 재생성
2. **기존(구) 버전의 md·html을 모두 `99 이전 버전/` 폴더로 이동** — 폴더에는 항상 최신 버전만 남긴다
3. 다른 명칭(`이전 버전`, `_이전 버전`, `99 과거 버전` 등) 사용 금지 — 저장소 전체 통일 규칙
