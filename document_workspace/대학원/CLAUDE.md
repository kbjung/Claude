## 4. ★ 문서 생성 규칙 — md 원본 + 스크립트로 HTML 생성 (2026-08-05 정립, 창업 CLAUDE.md와 공통)

**HTML을 직접 작성·편집하지 않는다.** 항상 md를 원본으로 쓰고, 아래 도구로 HTML을 생성한다.

```
python3 "_도구/build_doc.py" 문서.md          # 같은 폴더에 문서.html 생성
```

| 이유 | 내용 |
|------|------|
| 토큰 | 같은 내용이라도 HTML이 md 대비 **약 1.3배**(태그·CSS·JS). 편집 시 치환 문자열은 **약 2배** |
| 안정성 | HTML 문자열 치환은 태그 중첩·이스케이프로 실패 위험. md는 낮음 |
| 일관성 | 스타일이 스크립트 한 곳에 모여 있어 문서 간 편차가 없음 |
| 편집성 | 제이가 직접 수정·버전 비교하기 쉬움 |

**작업 절차**
1. md 작성·수정 (원본)
2. `build_doc.py`로 HTML 생성
3. **md와 html을 같은 버전명으로 함께 저장** (`{문서명}_YYYYMMDD_HHMM.md` / `.html`)
4. 이전 버전은 md·html 모두 `99 이전 버전/`으로 이동

> ⚠️ **html만 고치는 일이 없도록 한다.** html은 생성물이므로 직접 수정하면 다음 빌드에서 사라진다.
> 기존 html 전용 문서는 **다음 수정 시 md로 전환**한다.

**md 확장 문법** (build_doc.py가 처리)

| 문법 | 결과 |
|------|------|
| `{{ok:확인됨}}` `{{warn:미확인}}` `{{red:불가}}` `{{info:진행 중}}` | 색상 배지 (inline-block·nowrap 적용) |
| `\| {{tight}}항목 \| 내용 \|` | 해당 셀 `white-space:nowrap; width:1%` |
| ` ```copy 제목 ` … ` ``` ` | **복사 버튼**이 붙은 블록 (메일 본문·문안용) |
| `<!-- fields -->` | 성명·연락처·이메일 **입력칸** 생성. 복사 블록의 `[[NAME]] [[PHONE]] [[EMAIL]]`이 실시간 치환 |
| `:::ok` … `:::` | 초록 강조 박스 (결론·좋은 소식) |
| `:::note` … `:::` | 주황 강조 박스 (주의·경고) |
| `> 인용문` | 주황 박스 |

**도구 위치·동기화**
- 대학원 : `대학원/_도구/build_doc.py`
- 창업 : `사업/창업/_도구/build_doc.py`
- ⚠️ **두 사본은 항상 동일하게 유지한다.** 한쪽을 고치면 다른 쪽에도 반영할 것
  (두 프로젝트가 별도 폴더로 연결되어 있어 공용 상위 폴더를 쓸 수 없음)
- 의존성 : `pip install markdown --break-system-packages` (스크립트가 자동 설치 시도)
- 스타일을 바꿔야 하면 **스크립트의 CSS만** 수정하고 전 문서를 재생성한다

### 4-1. HTML CSS 체크리스트 (뉴스/리포트 등)

> 아래 항목은 `_도구/build_doc.py`의 CSS에 **이미 내장**되어 있다. 스크립트를 쓰면 자동 충족되며, 스크립트를 수정할 때만 확인하면 된다.

표·카드형 페이지에서 한국어 태그/배지가 잘리는 이슈가 반복 발생. 신규 HTML 작성 시 아래 체크 필수:

- **`.tag` 류 인라인 배지**: 반드시 `display: inline-block;` + `white-space: nowrap;` 지정 (한국어 4자 이상 텍스트도 줄바꿈/잘림 없이 표시)
- **테이블 분류 칼럼**: `td`에 `white-space: nowrap; width: 1%;` 적용 — 분류·상태 칼럼이 콘텐츠 너비만큼만 차지하고, 본문 칼럼이 남은 공간 사용
- **카드 내부 메타 영역**: 여러 링크/구분점이 들어갈 경우 `flex-wrap: wrap;` 추가 (모바일에서 줄바꿈 보장)
- **반응형 분기점**: `@media (max-width: 768px)`에서 grid 컬럼 1열, stats-row 2열 등 기존 패턴 유지
- **카드형 뉴스 그리드(2단 컬럼)에서 섹션 내 뉴스가 2건일 때**: 두 카드 모두 `full` 클래스를 빼고 `news-grid-2` 컨테이너에 넣어 한 줄에 나란히 채운다. 카드 1개에만 `full`을 지정하면 남은 카드가 반쪽 너비로 남고 옆에 빈 공간이 생기므로 금지 (2026-08-14, BIO AI 핵심뉴스에서 반복 발견되어 확정)
- 작성 완료 후 한국어 6자 이상 태그(예: "데이터베이스", "파트너십", "임상 데이터")가 포함된 셀이 있다면 시각적으로 한 번 검수
- 위 항목은 `09_ai/01_news/` BIO AI·AI 핵심뉴스처럼 build_doc.py를 거치지 않고 직접 HTML 카드 템플릿을 유지·복제하는 문서에도 동일하게 적용 — 매주 생성 시 직전 파일을 참고하되 이 체크리스트를 함께 확인
