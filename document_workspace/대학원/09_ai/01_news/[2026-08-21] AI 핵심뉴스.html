OpenAI·Anthropic·Google API 공통 취약점 — 추론 과정 31만건 유출

독일 ELLIS Institute와 Max Planck Institute 공동 연구진이 OpenAI·Anthropic·Google이 API 세션 간 숨겨진 추론(reasoning) 내용을 암호화할 때 공용 전역 키(global key)를 사용한 취약점을 발견, 논문 「Stealing Reasoning Traces from Proprietary LLM APIs」로 공개했다.
  • 세 회사 API에서 추론 블록 31만 5,320건을 복호화하고 공개 로그에서 API 키·비밀번호 등 실제 자격증명 182건을 확보
  • 모델 증류용 추론 탈취, 타 사용자 비공개 데이터 추출, 안전장치 우회 유해 콘텐츠 복원, 추론 블록 내 프롬프트 인젝션 은닉 등 4가지 악용 경로를 실증
  • 공개 시점 기준 주요 추출 공격은 재현 불가로 조치됐으나, 3사 모두 세션 간 추론 재사용·모델 전환 시 처리 방식을 수정
⚠️ 주요 프론티어 모델 3사가 동일한 구조적 취약점을 공유했다는 점에서 업계 전반의 API 보안 설계 재점검 필요성이 제기됨
