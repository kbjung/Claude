# 09_ai 폴더 작업 규칙

> **이 문서는 `09_ai/` 폴더에서 작업할 때 적용되는 전용 규칙입니다.**
> 공통 규칙(파일명·KST·HTML CSS 체크리스트·세션 요약)은 상위 `대학원/CLAUDE.md`를 참조한다.

---

## 1. 폴더 구조

```
09_ai/
├── 01_news/     ← AI·BIO AI 핵심뉴스 html 파일 (매주 월요일 자동 저장)
├── 02_paper/    ← AI 관련 논문·중요 paper 정리 문서
└── _sessions/   ← 세션 간 대화 요약 저장 (BIO AI 뉴스 관련 탐색·분석 대화)
```

---

## 2. 뉴스 파일명 규칙

`[YYYY-MM-DD] AI 핵심뉴스.html` / `[YYYY-MM-DD] BIO AI 핵심뉴스.html`

- 예시: `[2026-04-12] AI 핵심뉴스.html`
- 예시: `[2026-04-12] BIO AI 핵심뉴스.html`
- 날짜는 반드시 `TZ='Asia/Seoul' date +%Y-%m-%d` 명령으로 실제 KST 날짜 확인 후 사용 (공통 규칙 준수)

## 4. 뉴스 콘텐츠 기준

- **AI 뉴스**: 빅테크·AI 모델·정책·연구 동향 등 4~6개 카테고리
- **BIO AI 뉴스**: 빅파마 AI 파트너십·M&A, AI 신약개발 플랫폼, 펩타이드·단백질 AI 연구, 국내 동향 등 4~6개 카테고리
- 각 뉴스에 **날짜·출처·핵심 내용** 포함
- **논문이 포함될 경우 저자 소속·공동 연구기관 명시** (memory 파일의 `feedback_ai_news_format` 피드백 준수)
- 기존 HTML 파일의 디자인 스타일(카드형·색상·폰트 등) 그대로 유지
- HTML 작성 시 상위 CLAUDE.md의 **CSS 체크리스트** 반드시 준수 (특히 `.tag` nowrap, 분류 칼럼 width:1%)
- **한자(漢字) 사용 금지** — 본문·제목·요약표에 向·前·比·等 같은 한자를 쓰지 않는다. 한글 또는 영어로 표기 (예: "엔비디아向" → "엔비디아향", "前 총재" → "전 총재", "전년比" → "전년 대비"). 단, 외부 출처 기사 제목을 그대로 인용하는 Sources 섹션은 예외 (2026.08.14 확정)
- **카드 본문은 줄글 대신 개조식(불릿) 정리** — `news-card-body`(BIO AI)·`card-body`(AI)는 1~2문장 도입부만 줄글로 쓰고, 세부 내용(수치·기관명·날짜 등 핵심 사실)은 `<ul class="blist"><li>...</li></ul>` 불릿 2~3개로 정리한다. 한 카드에 3문장 이상 이어지는 줄글 단락 금지. BIO AI 핵심뉴스 템플릿에도 `.blist` CSS(▸ 불릿, blue/green/orange/red/purple 색상 클래스)를 AI 핵심뉴스와 동일하게 적용한다 (2026.08.14 확정, `[2026-08-14] AI 핵심뉴스.html`의 카드 형식을 표준으로 반영)
- **최상단 요약표는 4칼럼(이슈/영역/하이라이트/날짜) 개조식으로 간결하게** — `summary-box`(AI)·`highlight-box`(BIO AI)의 첫 표는 "핵심 내용"에 2~3문장 서술형 문장을 넣지 않는다. 각 셀은 짧은 명사구·키워드만 사용(예: "Hassabis 회장 이동·Jeff Dean 퇴사" / "Discovery Loop 창업"). `하이라이트` 칼럼은 `--accent1~5` 색상 중 관련 섹션과 맞는 색을 인라인 스타일로 강조. header-subtitle도 문장형 나열 대신 "카테고리1 · 카테고리2 · ..." 짧은 키워드 목록으로 작성 (2026.08.14 확정, BIO AI 핵심뉴스의 `highlight-table` 형식을 표준으로 AI 핵심뉴스에 역적용)
