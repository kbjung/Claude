## 0. 하이퍼랩이란 / K-Fold와의 관계

하이퍼랩은 히츠(HITS)가 제공하는 **AI 기반 신약개발 플랫폼(디지털 실험실)**입니다. 구조 기반 약물 발견(Structure-Based Drug Discovery, SBDD)을 축으로, 단백질 구조 등록부터 결합 예측·분자 설계·가상 스크리닝·ADME/T 예측까지 한 플랫폼에서 수행합니다.

이번에 신청한 **K-Fold 입문 특강**은 하이퍼랩의 AI 과학자(Bio Co-Scientist) 기능 중 **"구조 예측(K-Fold)"** — 단백질 3차원 구조를 예측하는 기능(단독 구조/복합체/삼중 복합체/대량 예측 지원)을 실습하는 과정으로 보입니다. 아래 「6. AI 과학자」 절에 관련 내용을 정리했습니다.

## 2. 랩스페이스(Labspace)

랩스페이스는 하이퍼랩이 제공하는 **디지털 실험실 단위**입니다. 조직 규모에 맞춰 아래처럼 운영할 것을 권장합니다.

| 단위 | 예시 |
|---|---|
| {{tight}}본부 | `#HITS` |
| {{tight}}부서 | `#신약개발본부` |
| {{tight}}팀 | `#의약화학팀` |
| {{tight}}실험실 | `#Drug Development Lab` |

### 랩스페이스 생성하기
1. 로그인 시 자동 이동하는 랩스페이스 목록 페이지에서 **`랩스페이스 만들기`** 클릭
2. 랩스페이스 유형 선택 (유형에 따라 제공 기능·가능한 연구가 달라짐)
3. 랩스페이스 이름 입력 (조직명/팀명 권장, 예: `HITS`, `Drug Discovery Lab`)
4. **`생성`** 클릭으로 완료

### OTP 보안 설정
1. OTP를 설정할 랩스페이스 클릭 → 스마트폰 OS에 맞는 OTP 앱 설치 (계정 이메일과 무관하게 사용 가능)
2. OTP 앱에서 QR 코드 스캔 → 랩스페이스 이름이 표시된 코드 생성 확인
3. 앱에 표시된 6자리 코드를 입력하면 등록 완료

{{warn:주의}} 일부 중국산 스마트폰(Xiaomi Redmi 시리즈 등)에서는 정상 동작이 확인되지 않았습니다. OTP 분실 시 화면 우측 하단 채널톡으로 관리자에게 재등록 문의.

### 멤버 관리 — 권한 표

| 역할 | 권한 |
|---|---|
| {{tight}}오너 | 랩스페이스 생성자. 멤버 초대·제외 가능 |
| {{tight}}어드민 | 멤버 초대 가능, 오너를 제외한 멤버 제외 가능 |
| {{tight}}멤버 | 조회만 가능 |

- 멤버 초대: `멤버 초대` → 이메일 입력 → 하이퍼랩 가입 안내 메일 자동 발송
- 멤버 제외: 대상 확인 → `제외하기` → OTP 입력 → 제외 안내 메일 발송
  {{warn:주의}} 프로젝트에 속한 멤버는 먼저 모든 프로젝트에서 제외한 뒤에만 랩스페이스에서 제외 가능

## 3. 프로젝트 & 토큰

### 토큰 사용 원리
계산 제출 시 토큰이 **할당**되고, 완료되면 **반환**됩니다. 토큰은 랩스페이스에 귀속되며, 모든 계산은 **선입선출(FIFO)** 방식으로 처리됩니다.

| 기능 | 토큰 수 | 설명 |
|---|---|---|
| {{tight}}하이퍼 ADME/T | 1 | In-vitro ADME/T 예측 |
| {{tight}}하이퍼 바인딩 | 3 | 결합에너지·3D 결합구조 예측 |
| {{tight}}하이퍼 디자인 | 6 | 신규 유도체 설계(Scaffold hopping) |
| {{tight}}하이퍼 바인딩 Co-Folding | 6 | 단백질 구조 + 결합에너지·3D 구조 동시 예측 |
| {{tight}}시퀀스 단백질 등록 | 6 | Sequence 타입 단백질 등록 |
| {{tight}}Hyper Screening X | 1 | 초대형 가상 라이브러리 기반 신규 분자 생성 |

{{info:참고}} 하이퍼 스크리닝은 토큰과 별개로 **스크리닝 포인트**를 소모하며, 소모된 포인트는 반환되지 않습니다.
토큰 현황은 좌측 사이드바 **[토큰 사용 현황]**, 플랜 정보는 랩스페이스 설정 **[플랜 & 토큰]**에서 확인합니다.

### 프로젝트 생성하기
프로젝트는 "AI 기반 신약개발 실험을 수행하는 독립된 연구 공간"으로, 프로젝트별로 멤버·표적 단백질을 따로 관리합니다.

1. 랩스페이스 접속 → 상단 메뉴 **프로젝트 리스트** 이동
2. 우측 상단 **프로젝트 생성** 클릭
3. 프로젝트 이름 입력 (표적 단백질명 포함 권장, 추후 수정 가능)
4. 표적 단백질 관련 정보 입력
5. **생성 완료**

### 프로젝트 관리
- `…` 버튼 → **[프로젝트 관리]**(이름·설명·타겟 단백질·TPP 수정) / **[프로젝트 멤버]**(초대·제외·역할변경)
- 멤버 초대: [프로젝트 멤버] → `멤버 초대` → 랩스페이스 등록 멤버 검색·선택 → 역할 확인 → `추가` → `초대하기`
- 멤버 제외(리더·매니저만 가능): `제외하기` → 데이터 이관 대상 선택(또는 삭제) → OTP 입력
  {{warn:주의}} 멤버 제외 시 해당 멤버가 만든 데이터가 삭제될 수 있음
- 프로젝트 삭제: [프로젝트 관리] → [프로젝트 삭제] → 프로젝트 이름 정확히 입력 → OTP → **영구삭제**

## 4. 단백질 등록 — SBDD의 출발점

하이퍼랩은 **구조 기반 약물 발견(SBDD)** 방식을 씁니다. AI 실험을 시작하려면 먼저 표적 단백질 구조를 **등록 → 활성화**해야 하며, 활성화된 단백질을 기준으로 실험 결과가 관리됩니다.

**절차**: 프로젝트 진입 → `단백질 관리` → `단백질 추가` → 유형 선택(3D 구조 / Sequence) → 등록 → 활성화

### 3D 구조로 등록하는 3가지 방법

| 방법 | 내용 |
|---|---|
| {{tight}}PDB ID | 실험적으로 결정된 구조(X-ray/Cryo-EM/NMR)를 RCSB PDB ID로 조회 |
| {{tight}}AlphaFold | 실험 구조가 없을 때 UniProt ID로 예측 구조 조회. {{warn:주의}} 리간드 결합 정보는 반영 안 됨 |
| {{tight}}파일 업로드 | 개인 소장·수정한 PDB 파일 직접 업로드 |

### Sequence로 등록하는 2가지 방법
- **검색 추가**: Gene name/Protein name/Organism/UniProt ID/PDB ID로 검색 → 옵션(Mutation, PTM, Coenzyme 등) 설정 → 등록 → 계산 완료 후 활성화
- **직접 입력**: Type(Protein/RNA/DNA/Coenzyme/Inorganic ion) 선택 → Copies·체인 정보 입력 → PTM·Binding site 설정(선택) → 등록

### 구조 등록 & 결합 부위 정의 (프로젝트 내 [Protein Structure] 탭)
1. `[Protein Structure]` 탭 → `+ 추가`로 구조 등록 시작
2. **결합 부위(Binding site) 정의** — 3가지 방법
   - 리간드 위치 기준: 결합 중인 리간드 선택 → 자동으로 결합 부위 박스 생성
   - 잔기(residue) 위치 기준: `Select Residue`로 잔기 선택(1개만 가능) → 박스 생성
   - 리간드 구조 파일 업로드: PDB/SDF/MOL2 형식 지원
   - `[Center]`, `[Box size]`는 1.0 Å 단위로 직접 조정 가능 (예측 분자 크기 고려해서 설정 권장)

## 5. Bench & 분자 관리 / 3D Viewer

**Bench**는 하이퍼랩 상의 "작업 디렉토리" 개념입니다.
- 개인 Bench: 본인만 열람 가능
- 공유 Bench: 다른 사용자와 분자 공유 가능

분자 상세 페이지에서는 기본 정보, Properties, 단백질별 계산 결과, 유사 분자 탐색이 가능하며, 파일 업로드(SDF/CSV 등)로 신규 분자 추가 또는 기존 데이터 병합이 가능합니다.

### 3D Viewer 주요 기능 (13종)
- 결합 부위 표시(원자·잔기·표면 투명도, Surface radius clipping)
- 상호작용 표시: 수용체-리간드 / 리간드-리간드 / 수용체-수용체 / 리간드-물 / 수용체-물
- 상호작용 유형 10종: 공유결합·충돌·반데르발스·수소결합·약한 수소결합·정전기적 결합·금속 상호작용·소수성 상호작용·Cation-Pi·Pi-Pi
- 표시 커스터마이징(색상·크기·라벨), 스크린샷, 전체화면, 2D Interaction Map

## 6. AI 과학자 (Bio Co-Scientist) — 자연어로 실험 요청하기

채팅창에 자연어로 요청하면 AI가 아래 작업들을 수행합니다.

| 카테고리 | 가능한 요청 예 |
|---|---|
| **구조 예측 (K-Fold)** | 단독 구조 / 복합체 / TPD·삼중 복합체 / 대량(Bulk) 예측 |
| **디자인 (RFdiffusion / RFantibody)** | De novo 단백질·펩타이드 바인더, Motif scaffolding, 대칭 올리고머, 항체·나노바디 |
| **리서치·정보 조회** | 단백질 서열, 실험 구조, 화학 구조, 에피토프, 도메인 구성 검색·주석 |
| **확인·해석** | 3D Viewer로 구조 확인, 자연어 해석 리포트, 다음 연구 전략 제안 |

### 좋은 결과를 얻는 요청 방법
1. **목표·작업 유형을 명확히** — 무엇을 위해 예측/설계하는지 명시
2. **시작 서열**은 직접 붙여넣거나 단백질 이름으로 지정 (이름만 줘도 표준 서열 자동 조회)
3. **복합체는 구성을 구체적으로** — 어떤 분자가 몇 개, 어떤 형태로 결합하는지
4. **디자인 요청 시 4가지 정보 필수**: 타깃, 생성할 개수, 시퀀스 길이, 결합 위치
5. 정확도를 높이려면 참고 구조 첨부, 결합 부위 힌트, 파일/Context 활용
6. 평가 기준과 다음 행동(선별 방식 등)까지 함께 요청하면 결과를 바로 활용 가능

### 결과 신뢰도 검증 — 4가지 도구
| 도구 | 확인 내용 |
|---|---|
| {{tight}}Trace | 채팅의 작업 블록 클릭 → 판단 근거, 호출한 도구/API, 검색·인용 출처, 실행 스크립트까지 상세 확인 |
| {{tight}}Confidence Score | pLDDT(잔기별 구조 신뢰도), PAE/iPAE(영역 간 상대 위치 신뢰도), pTM/ipTM(전체/복합체 신뢰도). 복합체는 ipTM↑·iPAE↓ 순으로 후보 선별 |
| {{tight}}구조 해석 | 수치뿐 아니라 핵심 인사이트·한계점을 자연어로 정리해 제공 |
| {{tight}}3D Viewer | 예측 구조 최대 5개 컨포머, Mol* 뷰어로 회전·확대·이동 |

무거운 계산은 실행 전 **예상 소요시간·예상 비용**을 보여주고 승인을 받은 뒤 시작합니다.

### 결과가 기대와 다를 때 대응 순서
1. Trace + Confidence Score로 어느 단계에서 갈렸는지, 불확실성인지 입력 문제인지 확인
2. "왜 이 부위에 결합하도록 예측됐나요?" 등 자연어로 근거를 직접 질문
3. 결과 하단의 추천 액션(무질서 영역 재설계, druggability 분석 등) 활용

| 상황 | 대응 |
|---|---|
| {{tight}}신뢰도 낮음 | 입력 파라미터 재검토, 샘플 개수 증가 |
| {{tight}}결합 문제 | 에피토프·포켓 재지정, 백본 재설계 또는 서열만 수정 |
| {{tight}}항체-항원 불안정 | 에피토프·CDR·framework·타깃 구조 정보 수정 |
| {{tight}}구조 부자연스러움 | 입력 서열·체인 지정·SMILES 확인, 시작점 변경 |

{{warn:주의}} 예측·디자인은 동시에 여러 개 진행 가능하지만, **중단 시 소진된 크레딧(토큰)은 환불되지 않습니다.**

|---|---|---|
| **하이퍼 바인딩** | 약물-표적 단백질 결합구조·결합에너지를 수 분 내 예측(4단계: 분자 등록→실행→결과 확인→SDF 저장) | 3 |
| **하이퍼 디자인** | Hit 화합물의 R-group 치환으로 신규 유도체 자동 설계, 치환 위치별 최대 50개 후보, 계층도로 관리 (전제조건: 하이퍼 바인딩 완료된 hit 화합물 필요) | 6 |
| **하이퍼 스크리닝** | 60만~100만 개 라이브러리를 24시간 내 가상탐색, 물리-딥러닝 융합 알고리즘으로 미학습 단백질도 일반화 예측. 라이브러리: diverse(약 100만개/24h/1만점), fragment(약 50만개/12h/5천점), demo(1천개/0.5h/1천점) | 포인트 별도 |
| **하이퍼 ADME/T** | LogP·Solubility·대사안정성·CYP억제(1A2/2C19/2C9/2D6/3A4)·hERG·P-gp·PAMPA 등 예측. 분자목록/상세정보/등록 시 3가지 실행 경로 | 1 |
| **Hyper Screening X** | 상용 빌딩블록+반응 기반 초대형 가상공간에서 합성 가능성 높은 신규 분자 생성. 모델 관리(단백질 구조로 AI 모델 학습)→분자 생성(합성경로 확인 가능)→장바구니(합성 견적 요청) | 1 |
| **Analysis / SAR 분석** | Bench 데이터 기반 자동 분석·그래프 시각화. Core·R-group 기준 치환기별 활성 비교 가능 | - |
| **In-house 라이브러리** | 자체 화합물 라이브러리 업로드(SDF/CSV, 500MB 이하, CSV는 Name·Structure(SMILES) 필수) 후 하이퍼 스크리닝과 연계 | - |
