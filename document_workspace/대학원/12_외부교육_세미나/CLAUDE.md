# 12_외부교육_세미나 폴더 작업 규칙

> **이 문서는 `12_외부교육_세미나/` 폴더에서 작업할 때 적용되는 전용 규칙입니다.**
> 공통 규칙(파일명·KST·HTML CSS 체크리스트·세션 요약)은 상위 `대학원/CLAUDE.md`를 참조한다.

---

## 1. 폴더의 성격

`03_수업/`(학위과정 정규 수업, 학기·학점 기준)과 구분되는 **대외 교육·세미나·특강·부트캠프** 자료 보관 폴더.

- 목적 ①: AI×바이오 분야 스펙·직무역량 강화
- 목적 ②: 진행 중인 연구과제(`01_연구과제/`)에 직접 활용
- 목적 ③: 장기적으로 창업(`창업/`)에 쓸 기술 무기 축적

## 2. 폴더 구조

```
12_외부교육_세미나/
├── 00_교육이수현황.md              ← 이수현황 트래커 (교육명·기관·일자·이수여부·활용메모·캘린더 등록현황)
├── [기관명]/                       ← 교육 주최 기관/플랫폼 단위 (예: 01_LAIDD) — 같은 기관에서 여러 교육을 들을 수 있으므로 기관 폴더를 먼저 두고, 교육은 그 아래 번호 하위 폴더로 누적
│   ├── 00_[기관명]_공통교재/        ← 특정 교육 회차에 종속되지 않는 일반 교재·자료 (예: 00_LAIDD_공통교재)
│   │   ├── 01_안내자료/             ← 다운로드 출처 스샷 등
│   │   ├── 02_교재원본/             ← 교재 PDF 원본
│   │   └── 03_한글번역본/           ← 영문 교재를 영한 대역(원본 이미지+한글번역)으로 개인 학습용 변환한 html (필요 시에만 생성)
│   └── [번호]_[교육명]/             ← 교육 1건 (예: 01_AI신약개발따라잡기_K-Fold입문특강)
│       ├── 01_안내자료/             ← 포스터·공지 스샷 등
│       ├── 02_강의자료_학습정리/     ← 강의 PDF·자료 원본 + 정리노트(md → build_doc.py로 html 생성)
│       └── 03_[플랫폼명]_사용법/     ← 교육에서 쓰는 외부 플랫폼(하이퍼랩 등) 사용자가이드 정리본 (필요 시에만 생성)
└── 99_관심교육_후보/                ← 신청 전, 관심 있는 교육 정보만 모아두는 곳
```

- 최상위는 **기관/플랫폼 단위**(`01_LAIDD` 등)로 만든다 — 같은 곳에서 추가 교육을 들을 가능성이 있으므로, 교육명으로 최상위 폴더를 바로 만들지 않고 기관 폴더 아래 번호 하위 폴더(`01_`, `02_`...)로 쌓는다 (2026.08.22 확정 — 처음엔 `01_LAIDD_AI신약개발따라잡기_K-Fold입문특강`처럼 기관+교육명을 한 폴더명에 합쳤다가, LAIDD에서 추가 교육을 들을 수 있다는 점을 반영해 `01_LAIDD/01_AI신약개발따라잡기_K-Fold입문특강/` 구조로 재조정)
- 특정 회차·강좌에 속하지 않는 일반 교재·자료(플랫폼에서 별도로 배포하는 PDF 등)는 기관 폴더 바로 아래 `00_[기관명]_공통교재/`에 모은다 (`01_`, `02_`... 특정 교육 하위 폴더와 구분)
- 새 교육을 들으면 해당 기관 폴더 아래에 `[번호]_[교육명]/` 하위 폴더를 만들고 `00_교육이수현황.md`에 한 줄 추가
- 교재 파일명에 "2차가공 및 재배포 금지" 등 저작권 고지가 있으면 그대로 보존하고, 다른 문서에 발췌·재가공할 때 출처 표기 필요
- 일정이 확정된 교육은 구글 캘린더(kbjoong11@gmail.com)에도 등록하고, `00_교육이수현황.md`의 "구글 캘린더 등록 현황" 표에 기록
- 학습 정리 문서는 상위 CLAUDE.md 4번 규칙(md 원본 + `_도구/build_doc.py`로 html 생성) 그대로 적용
- 교육에서 사용하는 외부 SaaS/툴의 공식 사용자가이드가 GitBook 등으로 공개되어 있으면, 웹에서 조사해 `03_[플랫폼명]_사용법/`에 md+html로 정리 (GitBook MCP는 제이 계정 소속 조직 문서만 접근 가능 — 타사 공개 문서는 WebFetch로 직접 조사)
